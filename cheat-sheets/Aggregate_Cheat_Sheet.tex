{\huge{\bf \textbf{\texttt{Aggregate} Class Cheat Sheet}}}

\raggedright
\texttt{\m Aggregate(name, exp\_el=0, exp\_premium=0, exp\_lr=0, exp\_en=0, exp\_attachment=None, exp\_limit=inf, sev\_name='',} \\
\texttt{\phantom{\m}sev\_a, sev\_b, sev\_mean, sev\_cv, sev\_loc, sev\_scale, sev\_xs, sev\_ps, sev\_wt, sev\_lb, sev\_ub, sev\_conditional, } \\
\texttt{\phantom{\m}occ\_reins, occ\_kind, freq\_name, freq\_a, freq\_b, freq\_zm, freq\_p0, agg\_reins, agg\_kind, approximate, note, hints)}${}^{[0]}$

The constructor follows the DecL clauses (exposure, severity, occurrence reinsurance, frequency, aggregate reinsurance). Usually built via \texttt{build('agg ...')}.
The following tables show all \texttt{\m methods}, and fields or properties (used interchangeably). Comments elucidate the meaning of more obscure entries.

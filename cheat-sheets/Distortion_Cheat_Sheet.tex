{\huge{\textbf{\texttt{Distortion} Class Cheat Sheet}}}

\raggedright

\texttt{\m Distortion(name, shape=None, $*$, display\_name='', $**$natural)} \\

\texttt{Distortion} is a factory base class: the call \texttt{Distortion('ph', 0.9)} dispatches on \texttt{name} to a registered subclass (\texttt{PHDistortion}, \texttt{TVaRDistortion}, \dots) and returns an instance. A distortion is an increasing, concave $g:[0,1]\to[0,1]$ with $g(0)=0$, $g(1)=1$, used to define a coherent risk measure / pricing functional. Create one by family with a named constructor (\texttt{\s Distortion.ph(0.9)}), or via DecL \texttt{distortion <NAME> <KIND> <SHAPE>}.
The following tables show all \texttt{\m methods}, \texttt{\s static / class methods}, and fields or properties (used interchangeably). Comments elucidate the meaning of more obscure entries.

{\bf Notes:}

[1]: \texttt{info}, \texttt{describe}, \texttt{stats\_df}, \texttt{density\_df}, and \texttt{plot} mirror the common reporting interface shared with \texttt{Aggregate} and \texttt{Portfolio} --- the same names do the analogous job on each class.

A distortion satisfies $g(0)=0$, $g(1)=1$, increasing and concave; the dual is $g^*(x) = 1 - g(1-x)$. Distorted price $= \int_0^\infty g(S(x))\,dx$.

{\huge{\textbf{\texttt{Portfolio} Class Cheat Sheet}}}

\raggedright
\texttt{\m Portfolio(name, spec\_list, uw=None, label=None, label\_map=None, note='', tags=(), doc='')} \\

A \texttt{Portfolio} is a collection of \texttt{Aggregate} units sharing a discretization grid; it adds diversification, capital allocation, and distortion pricing. \texttt{spec\_list} is a list of \texttt{agg} specs / programs; usually built via \texttt{build('port ...')}.
The following tables show all \texttt{\m methods}, and fields or properties (used interchangeably). Comments elucidate the meaning of more obscure entries.

{\bf Notes:}

[1]: matches \texttt{Aggregate}.
